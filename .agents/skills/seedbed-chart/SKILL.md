# Chart the excavation cartography

Use this skill as a thin entrypoint. All cartography conventions live in the
installed normative reference — `<planning-root>/docs/excavation/README.md`
(doctrine and campaign shapes, question lifecycle, gap classes, self-consumption
mechanics, the advisory boundary). Load and follow it instead of creating a
second policy here.

## Run the cartography action

1. Read `docs/excavation/README.md` at the relevant planning root; it is the
   policy source of truth. Load existing `doctrine.md` and campaign files when
   present.
2. Draft or amend autonomously from repository observables — user hints are
   optional bootstrap input, never required, and no human gate precedes a draft.
   Every topology claim carries observable pointers.
3. Respect the boundary both ways: cartography artifacts carry zero pool
   authority and never gate, license, or substitute for a dig gate, promotion,
   or deletion basis; digs themselves run under the excavation flow (the
   `seedbed-excavate` skill), never under this one.
4. Report progress as frontier burn-down plus pool accrual — never a completion
   percentage.

Do not duplicate, reinterpret, or add cartography policy in this shim; policy
changes belong in `docs/excavation/README.md`.
